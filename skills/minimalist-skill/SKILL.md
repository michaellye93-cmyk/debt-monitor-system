# Minimalist Skill

## Core Principles
- **Grid Dominance**: Everything must align to a strict grid.
- **Monochrome+**: Use a primary accent color sparingly.
- **Crisp Details**: 1px borders, subtle dividers, and high-contrast typography.
- **Function over Flourish**: Every element must serve a purpose.

## Aesthetic Guide
- Font: `Inter` or `Geist`.
- Corners: Subtle rounding (4px-8px).
- Palette: High-contrast grays and sharp blacks/whites.
