# Taste Skill

This skill ensures that all frontend implementation exceeds standard "MVP" quality. It focuses on premium aesthetics, thoughtful motion, and refined spacing.

## 🎛️ Settings
Adjust these numbers (1-10) in your prompt to fine-tune the output:
- **DESIGN_VARIANCE (5)**: How experimental the layout is. (1-3: Clean/centered | 8-10: Asymmetric/modern)
- **MOTION_INTENSITY (5)**: How much animation there is. (1-3: Simple hover | 8-10: Magnetic/scroll-triggered)
- **VISUAL_DENSITY (4)**: How much content fits on one screen. (1-3: Spacious/luxury | 8-10: Dense dashboards)

## 🎨 Design Rules
1. **Premium Palette**: Never use default CSS colors. Use HSL-based palettes with subtle depth.
2. **Glassmorphism**: Favor backdrop-blur and subtle borders for cards.
3. **Refined Typography**: Use `Inter`, `Outfit`, or `Playfair Display`. Ensure hierarchy via font weight and letter spacing.
4. **Motion First**: Every interactive element must have a transition. Use spring-based motions for a "premium" feel.
5. **Anti-Slop**: No generic "Lorem Ipsum". Every bit of copy should feel intentional.

## 🚀 Implementation Workflow
1. **Audit**: Analyze the requirements and identify the "Hero" moment.
2. **Setup**: Define the design tokens (colors, spacing, fonts).
3. **Build**: Implement the layout with a focus on responsiveness.
4. **Polish**: Add the micro-animations and final visual tweaks.
